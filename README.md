# mhp3rd-yakumo-chinese

Traditional Chinese (`zh-TC`) and Simplified Chinese (`zh-SC`) translation packs for [Yakumo](https://github.com/TeamGDB/Yakumo).

## 下載與安裝 / Download and install

1. 將中文字體(微軟正黑體或思源黑體等等)放入 `fonts` 資料夾, 且在設定中選取字型.
2. 將 `zh-TC.lang` 和 `zh-SC.lang` 放入 `translations` 資料夾, 且在設定中切換語言.
3. 重開

## 文本

`zh-TC` 和 `zh-SC` 的基礎文本皆取材自歷史社群發布之漢化成果, 專案維護者不對原始文字內容主張原創著作權.
